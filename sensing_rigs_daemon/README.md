## Description

This project contains a daemon written in C, which is aimed to run in the background of a Raspberry PI 5 with "*Raspberry Pi OS Lite (64-bit)*" as main operating system. 
This is the main software component of the phototrap, with the objective to handle the stereo image acquisition and its power management.

All the files generated by the running daemon are located under "**/demon/run/**", in particular:
 - "*sensing_rigs_daemon.pid*", contains the last PID used by the daemon, making easier to kill it when needed.
 - "*sensing_rigs_daemon.log.d*", directory containing all the log files generated by the daemon, separated by date. The daemon will not remove this files and will always try to append to them.

In the main release, the stereo images will be saved under "**~/run/captures/**" and they will be divided by whichever camera took them ("*rx*" or "*lx*") as subdirectories, and saved by its Unix epoch timestamp in "**.jpg**" format. However, this development version will not have such feature, since the cameras are present only in the physical one and not inside a container.

To relieve the system from these captures, and avoid filling up the disk space, a communication system with the exterior will be implemented on future releases.

To lighten the computational weights for the Raspberry PI 5, the algorithms regarding image enhancement/recognition are lefted to be computed off-site.

The daemon main loop can be abstracted in the following points:
- Check voltage:
    - If an undervoltage condition is found, terminate the daemon and warn the system.
- Check temperature:
    - If the CPU exceeds a certain threshold, terminate the daemon and warn the system.
- Check if there is enough disk space for a new stereo image:
    - If it is not sufficient terminate the daemon and warn the system.
- Capture a stereo image, if the cameras are working.
- Save the stereo image with its timestamp.
- Repeat.

All these tasks are logged throught a custom static logging system, which is multithreaded and performs asynchronous writing to the log file.

## Installation

"*GNU Make*" is used to build this project. To build the sorce code:

```bash
make
```

To make the executable system-available, copying it into "**/usr/local/bin**", use:

```bash
make install
```

To execute it use:

```bash
sensing_rigs_daemon
```

Or if not installed:

```bash
./sensing_rigs_daemon
```

To remove the executable from "**/usr/local/bin**" use:

```bash
make uninstall
```

To delete all build files inside "**./build/**" and the executable use:

```bash
make clean
```

To easily kill a running daemon:

```bash
kill $(cat /demon/run/sensing_rigs_daemon.pid)
```

If the daemon receives a *SIGHUP* it changes its current image acquisition state. Meaning that it will enable/disable it accordingly.

```bash
kill -SIGHUP $(cat /demon/run/sensing_rigs_daemon.pid)
```
